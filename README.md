# Рейтинг участников соревнований на бинарном дереве поиска

Курсовая работа по АиСД, МАИ, группа М7О-406БВ-23, Сокольников Ярослав.
Программа полностью оттестирована и проверена. Синтаксис, оформление кода, вывод в консоль, вывод в текстовый файл, взаимодействие с пользователем и всё остальное сделал как в своих прошлых программах по АиСД, ТРПО, ПЯВУ (можно сказать, по стандарту, к которому нас учили все это время)

Приложение для ведения рейтинга участников.
Записи хранятся в самостоятельно реализованном бинарном дереве поиска с ключом (баллы, идентификатор).

В программе есть:
1) tree.h, tree.cpp - бинарное дерево поиска
2) input.h, input.cpp - ввод и проверка данных
3) fileio.h, fileio.cpp - загрузка и сохранение рейтинга
4) main.cpp - меню и диалоги
5) rating.txt - пример входных данных


Сборка на CLion, стандарт C++17, ОС Windows.
Исходные файлы и файлы данных в кодировке Windows-1251.
